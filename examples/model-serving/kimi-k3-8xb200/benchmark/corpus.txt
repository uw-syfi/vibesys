Request Factory generates independent synthetic prompts from a deterministic corpus. A prompt is a sequence of token IDs selected from this text corpus with the model tokenizer. Each request is independent, and requests do not share a conversational prefix. The benchmark targets a long-context serving workload with thousands of prompt tokens followed by a generated completion. The measured server should process every requested token and return token IDs in the streaming completion response. The driver records the time to complete each request and the aggregate rate of generated output tokens. Input processing includes tokenization and prefill. Output processing includes decoding and generation. The benchmark varies prompt content across the request stream while keeping the prompt length and output target fixed. This makes runs repeatable while exercising long-context inference. The server can schedule concurrent requests and batch them as its serving implementation permits. A request is successful only when the server returns the requested completion length without an error. Incomplete responses and token-count mismatches invalidate the run. Benchmark results describe the configured model, tokenizer, server implementation, hardware, request concurrency, and trace. They should be compared only when those conditions match. The synthetic prompt text is not intended to evaluate semantic answer quality. Correctness is checked separately by the bundle accuracy checker.
