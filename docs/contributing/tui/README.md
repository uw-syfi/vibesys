# TUI contributor docs

TUI-specific contributor docs live in this folder.

- [TUI conventions](./conventions.md): display and interaction conventions.
- [TUI keybinding matrix](./keybinding-matrix.md): source-cited comparison of
  keybinding conventions across Claude Code, Codex, Vim, LazyVim, GNU
  Readline, and WCAG 2.2, ahead of adopting a TUI keymap.
- [TUI architecture](../tui-architecture.md): package ownership and dependency rules.

Changes confined to this folder are within the delegated `tui` capability in
[`.github/delegated-merge.toml`](https://github.com/uw-syfi/vibesys/blob/main/.github/delegated-merge.toml).
