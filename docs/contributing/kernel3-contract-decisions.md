## Persisted format and verification

Bump envelope schema 2 to 3 and provide an explicit pure selected migration. Freeze a version-2 fixture serialized by the untouched current-main models before editing. Preserve identities, budget consumption, unknown ownership and original deadlines. Reconstruct new proof only from exact existing facts; otherwise encode unavailable/unverified data, or reject a migration that would invent executable authority. Migrated envelopes require fresh recovery; prepared resumes and attempt measurements without reconstructable new authority are rejected with the exact request path. No new SOT baseline entries. Properties exercise public `step`, projections and codecs, including missing/corrupt proof variants. Shared routing remains independent of leaf implementation.
