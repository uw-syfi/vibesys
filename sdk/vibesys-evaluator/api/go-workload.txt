package workload // import "github.com/uw-syfi/vibesys/sdk/vibesys-evaluator/loadgen/workload"

Package workload is the Go front end of vibesys-evaluator: a task's
request generator written in Go. It has the concepts of the Python SDK's
vibesys_evaluator.microservices: a Workload is a dataset, a model built from it,
and a weighted mix of Operations; each Operation builds a Request (Steps from
Get, Post and Put, a Template filled from an earlier step's response, the
info it was built from, an exclusive key), a write's Apply updates the model,
and Check says what is wrong with a response after the phase. The dataset and
the model are any Go types, so a task's existing reference model and checks
serve as they are. Rand is bit-identical to the Python SDK's Rand.

Main is the generator command that loadgen and the phase pod run (see "Generator
command line" in sdk/vibesys-evaluator/docs/spec.md): `generate` writes the
request stream on standard output until loadgen closes it, and `check` checks
the phase's results afterwards. For the same PhaseInput, a Go and a Python
generator of the same workload write the same stream.

CONSTANTS

const DefaultReadSample = 0.1
    DefaultReadSample is the share of a read-only operation's responses that are
    checked when Operation.Sample is 0.


FUNCTIONS

func Main[D, M any](w Workload[D, M])
    Main runs the generator command in os.Args and exits: `generate` writes
    the phase's request stream on standard output until it is closed,
    and `check` checks the phase's results and writes its PhaseOutput
    (sdk/vibesys-evaluator/docs/spec.md, "Generator command line"). Standard
    error carries only logs. A task's generator binary is `func main() {
    workload.Main(w) }`.


TYPES

type Call struct {
	// Info is the Request's Info as JSON (a JSON object).
	Info json.RawMessage
	// Pending is true while the phase is generated.
	Pending bool
	// Start is when its first step was sent; End when its last response was complete.
	Start, End time.Time
	// OK is true when every step answered with an expected status.
	OK bool
	// Responses has one per step that was sent.
	Responses []Response
}
    Call is one operation as sent: what it was built from, when it ran and what
    came back. While a phase is generated, a write's Apply sees it Pending:
    no times, OK false and no responses.

func (c Call) DecodeInfo(v any) error
    DecodeInfo unmarshals the call's Info into v (encoding/json).

type Field struct {
	Key   string
	Value any
}
    Field is one key and value of an Object.

type Object []Field
    Object is a JSON object whose keys keep their order, for a JSON body sent
    with the same bytes as the Python SDK sends a dict ({"user": u, "password":
    p} is Object{{"user", u}, {"password", p}}). A Go map is sent with its keys
    sorted; a struct with its fields in order, named by their `json` tags.

func (o Object) MarshalJSON() ([]byte, error)
    MarshalJSON writes the object with its keys in order.

type Operation[M any] struct {
	// Name is unique in the workload: ^[a-z][a-z0-9_]{0,62}$.
	Name string
	// Weight is its share of the mix, relative to the other weights; > 0.
	Weight float64
	// Build builds one request from the model and the operation's own stream.
	Build func(model M, rand *Rand) Request
	// Check says what is wrong with a response (nil when it is right), after the phase, over
	// the validation sample. Without it the operation is never checked.
	Check func(model M, call Call) error
	// Apply makes the operation a write: it records it in the model, pending while the phase
	// is generated and with its outcome afterwards. An error fails the phase.
	Apply func(model M, call Call) error
	// Sample is the share of operations checked, in (0, 1]; 0 means the default: 1 for writes
	// (which may not set less), DefaultReadSample for other operations.
	Sample float64
}
    Operation is one operation of the mix.

type Option func(*stepBuilder)
    Option sets one part of a Step: Query, Header, Form, JSON, Body, Capture,
    Expect.

func Body(body []byte) Option
    Body sets a body sent as is.

func Capture(name, pointer string) Option
    Capture takes a value from the step's response by JSON pointer (such as
    "/token"), for later steps of the request to send with Ref(name).

func Expect(statuses ...int) Option
    Expect sets the statuses that count as success (200 when not set).

func Form[V Text](name string, value V) Option
    Form adds a field of a URL-encoded form body.

func Header[V Text](name string, value V) Option
    Header adds a request header.

func JSON(value any) Option
    JSON sets a JSON body (Content-Type: application/json unless a Header
    sets one), encoded as the Python SDK encodes its json argument: compact,
    non-ASCII escaped, an Object or struct in field order, a map with its keys
    sorted; a Template inside becomes a JSON string with the captured value
    inserted.

func Query[V Text](name string, value V) Option
    Query adds a query parameter, URL-encoded by loadgen.

type Rand struct {
	// Has unexported fields.
}
    Rand is a deterministic random stream named by a seed and labels,
    bit-identical to the Python SDK's Rand: NewRand(seed, labels...) here and
    Rand(seed, *labels) there draw the same values with the same methods,
    on every platform (sdk/vibesys-evaluator/fixtures/rand.json checks it).
    The algorithms are part of the versioned contract: SplitMix64 from a state
    that FNV-1a folds the labels into. A Rand is not safe for concurrent use.

func NewRand(seed uint64, labels ...any) *Rand
    NewRand starts the stream of seed and labels. A label is a string or a
    non-negative integer (any integer type); NewRand panics on any other label.

func (r *Rand) Below(n int) int
    Below returns an integer in [0, n): one draw modulo n. It panics when n < 1.

func (r *Rand) Child(labels ...any) *Rand
    Child returns the stream NewRand(seed, parentLabels..., labels...), whatever
    this one has drawn.

func (r *Rand) Normal() float64
    Normal returns an approximately standard normal value: Irwin-Hall of four
    uniforms, within 2 sqrt(3).

func (r *Rand) Random() float64
    Random returns a float64 uniform in [0, 1), from 53 bits of one draw.

func (r *Rand) Uint64() uint64
    Uint64 returns one raw draw (Python: below(2**64)).

func (r *Rand) Weighted(weights []float64) int
    Weighted returns an index drawn with probability proportional to its weight;
    never one of weight 0. Integer weights draw Below(sum) and walk the weights;
    other weights draw Random() * sum (an exactly rounded sum, as Python's
    math.fsum). It panics on an empty list, a negative or non-finite weight,
    or a sum that is not positive.

func (r *Rand) Zipf(n int, s float64) int
    Zipf returns a rank in [0, n) with weight (rank + 1)^-s, by the inverse
    CDF of one uniform draw; 0 is the most likely. It panics when n < 1 or s is
    negative or not finite.

type Request struct {
	Steps     []Step
	Info      any
	Exclusive string
}
    Request is what one operation sends: Steps in order on one client, with one
    latency.

    Info describes what the request was built from (a JSON object: a map,
    a struct or an Object; nil is {}); it is not sent, and comes back as JSON
    in the Call that Check and Apply receive. Requests with the same non-empty
    Exclusive key (at most 256 bytes) never run at the same time, and run in
    stream order.

type Response struct {
	// Status is the HTTP status; 0 when no response arrived.
	Status int
	// Body is the body (operations in the validation sample keep it whole).
	Body []byte
}
    Response is one step's response.

type Step struct {
	// Has unexported fields.
}
    Step is one HTTP call of a request, built by Get, Post or Put with Options.

func Get[P Text](path P, options ...Option) Step
    Get is a GET of path (starting with "/") below the target.

func Post[P Text](path P, options ...Option) Step
    Post is a POST of path (starting with "/") below the target, with at most
    one of Form, JSON and Body.

func Put[P Text](path P, options ...Option) Step
    Put is a PUT of path (starting with "/") below the target; its options are
    Post's.

func (s Step) String() string
    String shows the method and path.

type Template struct {
	// Has unexported fields.
}
    Template is a text made of literal parts and values captured by earlier
    steps of the same request (Ref): Concat("Bearer ", Ref("token")).

func Concat(parts ...any) Template
    Concat joins strings and Templates into one Template. It panics on any other
    argument.

func Ref(name string) Template
    Ref is the value an earlier step of the same request captured as name
    (Capture). It panics on a name outside ^[a-z][a-z0-9_]{0,62}$.

func (t Template) String() string
    String shows the template with its refs as {name}.

type Text interface{ ~string | Template }
    Text is what a path, query value, header value or form value may be:
    a string or a Template.

type Versions[K comparable, V comparable] struct {
	// Has unexported fields.
}
    Versions holds the values written to each key, with when, to say what a
    read may show: the Python SDK's Versions. A read that ran over [start,
    end] may show, per key, the latest value acknowledged more than the bound
    before it started (the default if there is none), or any value whose write
    started before the read ended and was not certainly overwritten before the
    read started. A write that failed counts as possibly applied, at any time
    after it started.

func NewVersions[K comparable, V comparable](bound time.Duration) *Versions[K, V]
    NewVersions tracks the values of keys whose writes become visible within
    bound (>= 0).

func (v *Versions[K, V]) Allowed(key K, def V, start, end time.Time) []V
    Allowed is the values a read of key over [start, end] may show, oldest
    first, distinct; at least one. def is the key's value before any write (the
    seeded one).

func (v *Versions[K, V]) Latest(key K, def V) V
    Latest is the last value written to key, pending writes included; def if
    none: what generation builds on.

func (v *Versions[K, V]) Write(key K, value V, call Call)
    Write records that call wrote value to key (in application order per key),
    pending or with its times and outcome.

type Workload[D, M any] struct {
	// Dataset loads the task's dataset from the file the orchestrator passes (--dataset: the
	// JSON that the Python dataset() encodes, see docs/spec.md); once per process, before the
	// model. Nil when the model needs no dataset (D's zero value is passed).
	Dataset func(path string) (D, error)
	// Model builds a phase's model from the dataset and the sample's model stream (the same in
	// every phase of a sample).
	Model func(data D, rand *Rand) (M, error)
	// Operations is the mix; names are unique.
	Operations []Operation[M]
}
    Workload is the dataset, the model the operations share, and the operations:
    the Python SDK's Workload[D, M]. D and M are any Go types the writer has:
    a task's existing reference model and its checks fit as they are.
