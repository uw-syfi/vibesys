package k8s // import "github.com/uw-syfi/vibesys/sdk/vibesys-evaluator/go/k8s"

Package k8s deploys a task's application into a Kubernetes cluster and acts on
it: it builds the images with BuildKit, applies the manifest into a namespace
of its own, waits until the application serves, runs the package's pods (seed,
probe, phase) in that namespace, applies fault actions (restart one or every pod
of a Deployment, exec a command in a pod, wait for readiness again) and deletes
the namespace on every exit path.

It is the Go core behind the Python `microservices.k8s.App` and the
`vibesys-evaluator k8s` subcommands. kubectl and buildctl run as subprocesses,
behind the KubeAPI and Builder interfaces; package k8stest holds an in-memory
cluster and builder for tests.

The cluster is the one the environment gives: KUBECONFIG, VIBESYS_K8S_REGISTRY
and VIBESYS_K8S_BUILDER (see ParseEnvironment).

	WorkDir    = Root + "/work"
	ControlDir = Root + "/control"

	PodLabel = "vibesys.dev/evaluator-pod"

    The package's own pods (seed, probe, phase): their Job objects and the file
    exchange.

    A pod of the package runs the task image under a small shell wrapper:

     1. it waits until CONTROL/ready exists; the caller first writes the
        input files into WorkDir and that marker last, in one tar stream
        (KubeAPI.PutFiles);
     2. it runs the command, which leaves its outputs in WorkDir and its output
        in the pod log, and writes the exit status to CONTROL/exit;
     3. it waits until CONTROL/collected exists, so the caller can copy WorkDir
        out of the running container, then exits with the command's status.

    The inputs and outputs travel through the API server's exec stream, so no
    ConfigMap size limit applies, and the Job's activeDeadlineSeconds ends a pod
    nobody collects.

func Sweep(ctx context.Context, src AppSource, c Cluster) ([]string, error)
    Sweep deletes this task's namespaces that killed samples left behind and
    returns their names.

    Only namespaces labelled with the App's name, named with its prefix and
    older than the longest a job may run plus a margin are deleted, each only if
    it still has the UID it was listed with, so a concurrent sample's namespace
    or another task's is never touched.

func TaskTimeout(taskDir string) (time.Duration, error)
    TaskTimeout is the longest a job of the task may run: the larger of the two
    timeout_seconds of the task's vibesys.input.toml.

func TreeDigest(root string) (string, error)
    TreeDigest is 16 hex digits over every file's relative path, mode
    (executable or not) and content. It is the digest the Python implementation
    computed, so an image built by either is found by the other.

func Unready(workloads []Workload, pods []Pod, names map[string]bool, replaced map[string]bool) []string
    Unready says why each workload (of names, when not nil) does not serve with
    all its replicas; nil when all do. A workload serves when its controller
    has seen its spec, exactly `replicas` of its pods exist that are neither
    terminating nor among the replaced UIDs, all of them Ready, and its status
    counts every replica ready, available and updated.

func UsageDelta(before, after map[string]Usage) map[string]float64
    UsageDelta is the CPU seconds each pod used between two snapshots (a pod new
    since before counts from 0).


TYPES

type App struct {
	// Name is the task's application name (lowercase letters, digits and dashes). It labels the
	// namespaces of the task, so the sweep of stale namespaces only ever deletes this task's.
	Name string
	// Manifest is the manifest's path relative to the task directory. ${NAMESPACE} and every
	// key of Images are substituted; any other ${...} is an error. Only namespaced application
	// kinds are accepted (see AllowedKinds).
	Manifest string
	// Images maps a manifest variable to a candidate directory (relative to the project root),
	// each built with its own Dockerfile and tagged by a digest of the directory.
	Images map[string]string
	// Gateway is the base URL of every request, http://<service>:<port>, a Service of the manifest.
	Gateway string
	// DataTier is a label selector (key=value[,key=value]). The objects it selects and every
	// non-workload object are applied first and waited for; then the seed runs; then the
	// remaining workloads are applied. Empty: the whole manifest serves before the seed runs.
	DataTier string
	// HasSeed says the deploy runs a seed pod (Deploy is given its command).
	HasSeed bool
	// Restartable are the Deployments the fault actions may restart, exec in, stop and start.
	Restartable []string
	// Caches are the cache Deployments the fault actions may empty in place, with their protocol.
	// They may also be restarted and exec'd in.
	Caches map[string]CacheKind
}
    App is an application on Kubernetes: what to build, what to apply, how to
    tell it serves. It is the Go form of Python's `microservices.k8s.App`;
    the fields mean the same.

func (a App) Validate() error

type Deployment struct {
	App       App
	Namespace string
	TaskImage string
	Gateway   Gateway
	// Images are the candidate images by manifest variable, and BuildSeconds the seconds each
	// image took; both only on a Deployment made by Deploy.
	Images       map[string]string
	BuildSeconds map[string]float64

	// Has unexported fields.
}
    Deployment is an App in its namespace. Deploy makes one that owns the
    namespace; Attach one that does not. Methods are safe for concurrent use
    except Close.

func Attach(ctx context.Context, src AppSource, namespace string, c Cluster) (*Deployment, error)
    Attach makes a Deployment for a namespace another process deployed (the
    fault actions); it never deletes it.

func Deploy(ctx context.Context, src AppSource, seed *PodCommand, c Cluster) (*Deployment, error)
    Deploy sweeps, builds, deploys into a fresh namespace, seeds and probes, and
    returns the serving Deployment. The caller owns the result and must Close
    it. On any failure here, including the context's cancellation (a signal),
    the namespace is deleted before the error returns.

func Owned(app App, namespace, uid string, c Cluster) *Deployment
    Owned makes a Deployment that owns an existing namespace, for a process that
    closes what another one deployed: Close deletes the namespace if it still
    has the UID. It reads no manifest.

func (d *Deployment) Close(ctx context.Context, opts CloseOptions) error
    Close deletes the namespace, if this Deployment owns it; it is idempotent.
    A cancelled ctx does not stop the deletion request: only its wait.

func (d *Deployment) Exec(ctx context.Context, target ExecTarget, argv []string, timeout time.Duration) ([]PodExec, error)
    Exec runs argv in a pod, or in the pods of a Deployment, and returns every
    pod's answer; a nonzero exit is a result, not an error. The Deployment must
    be one of the App's Restartable or Caches.

func (d *Deployment) Flush(ctx context.Context, cache string) error
    Flush empties a cache in place, on every pod of its Deployment, then probes.

func (d *Deployment) Probe(ctx context.Context) error
    Probe runs loadgen probe from a pod: every ready request succeeds twice per
    ready gateway pod.

func (d *Deployment) Restart(ctx context.Context, deployments []string, opts RestartOptions) ([]ReplacedPod, error)
    Restart deletes one pod (the first by name) or every pod of each Deployment
    at once. Unless opts.NoWait it returns when no deleted pod remains, every
    workload serves with all replicas and the probes pass.

func (d *Deployment) RunPod(ctx context.Context, role Role, command PodCommand, timeout time.Duration, opts RunOptions) (PodRun, error)
    RunPod runs a command of the task image in a pod of the namespace and
    collects WorkDir.

    The pod gets command.Inputs in WorkDir before the command starts;
    the files the command leaves there are copied into the outputs directory.
    A nonzero exit is returned, not an error (the caller judges it); a pod that
    cannot start, dies or runs past the timeout is an error with its log tail
    (an *OutOfMemoryError when the kernel killed it at its memory limit).

func (d *Deployment) Start(ctx context.Context) error
    Start scales the restartable Deployments back to the manifest's replicas,
    waits and probes.

func (d *Deployment) Stop(ctx context.Context) error
    Stop scales every restartable Deployment to 0 and waits until their pods are
    gone.

func (d *Deployment) UID() string
    UID is the namespace's UID once it is created ("" before).

func (d *Deployment) Usage(ctx context.Context, label string) (map[string]float64, error)
    Usage returns each pod's CPU seconds since the previous snapshot, logs it
    and writes pod-usage-<label>.json into the artifacts. It is diagnostics
    only: a cluster that does not give kubelet stats logs why and returns nil.
    The previous snapshot is kept in the Environment's WorkDir, so successive
    processes of one deploy share it.

func (d *Deployment) WaitReady(ctx context.Context, opts WaitOptions) error
    WaitReady waits until every workload (of opts.Deployments) serves with all
    its replicas, none of them a replaced pod, then probes through the gateway.

func (d *Deployment) WaitServing(ctx context.Context, names, replaced map[string]bool, timeout time.Duration) error
    WaitServing waits until every workload (of names, when not nil) has all its
    replicas Ready and available, none of them among the replaced pod UIDs.

type KubeAPI interface {
	// CreateNamespace creates a namespace with its labels in one request.
	CreateNamespace(ctx context.Context, name string, labels map[string]string) (Namespace, error)
	// Namespaces lists the namespaces whose labels include every pair of selector.
	Namespaces(ctx context.Context, selector map[string]string) ([]Namespace, error)
	// DeleteNamespace asks for deletion of the namespace if it still has this UID, without
	// waiting for it. ErrConflict when it has another UID, ErrNotFound when gone.
	DeleteNamespace(ctx context.Context, name, uid string) error
	// Apply is a server-side apply of the objects into the namespace.
	Apply(ctx context.Context, namespace string, objects []Object) error
	// Workloads lists the Deployments and StatefulSets of the namespace.
	Workloads(ctx context.Context, namespace string) ([]Workload, error)
	// Pods lists the pods of the namespace (whose labels include selector, when given).
	Pods(ctx context.Context, namespace string, selector map[string]string) ([]Pod, error)
	// DeletePods deletes the pods; one already gone is not an error. It does not wait.
	DeletePods(ctx context.Context, namespace string, names []string, graceSecs int) error
	// Scale sets a Deployment's replica count.
	Scale(ctx context.Context, namespace, deployment string, replicas int) error
	// Exec runs argv in the pod's first container.
	Exec(ctx context.Context, namespace, pod string, argv []string, timeout time.Duration) (ExecResult, error)
	// PutFiles writes files into a directory of the running pod, in the order given.
	PutFiles(ctx context.Context, namespace, pod, directory string, files []File) error
	// GetFiles copies every file of the pod's directory into the local directory into and
	// returns their relative names, sorted.
	GetFiles(ctx context.Context, namespace, pod, directory, into string) ([]string, error)
	// Logs is the pod's log (its previous container's with previous); "" when there is none.
	Logs(ctx context.Context, namespace, pod string, tail int, previous bool) (string, error)
	// PodStats is the kubelet counters of the namespace's pods on a node, by pod name.
	PodStats(ctx context.Context, namespace, node string) (map[string]PodStats, error)
}
    KubeAPI is what the deploy layer does to a cluster. Every call has a
    deadline of its implementation; every failure is a *KubeError (ErrNotFound
    and ErrConflict classify some) or the context's error.

type KubeError struct{ Message string }
    KubeError is what the cluster refused or failed; the message says which and
    why.

	// (WorkDir/<pod name> of the Environment by default).
	Outputs string
	// Name is the pod's Job name (vse-<role>-<n> by default, a random suffix instead of n from
	// a process that did not deploy); it must be unique in the namespace.
	Name string
}
    RunOptions are the optional parts of RunPod.

type Size struct{ CPU, Memory string }
    Size is a pod's CPU and memory (requests equal limits).

type SystemClock struct{}
    SystemClock is the real time.

func (SystemClock) Now() time.Time
    Now implements Clock.

func (SystemClock) Sleep(ctx context.Context, d time.Duration) error
    Sleep implements Clock.

type Usage struct {
	Workload   string  `json:"workload"`
	CPUSeconds float64 `json:"cpu_seconds"`
	RxBytes    int64   `json:"rx_bytes"`
	TxBytes    int64   `json:"tx_bytes"`
}
    Usage is the CPU seconds and network bytes of one pod since it started,
    and its workload.

type WaitOptions struct {
	// Deployments to wait for; every workload of the namespace when empty.
	Deployments []string
	// Replaced are the UIDs of pods that must be gone (a restart's, see ReplacedPod.UID).
	Replaced []string
	// Timeout is WaitSecs when zero.
	Timeout time.Duration
	// NoProbe skips the probes through the gateway that follow readiness.
	NoProbe bool
}
    WaitOptions say what WaitReady waits for.

type Workload struct {
	Kind       string // Deployment or StatefulSet
	Name       string
	Labels     map[string]string
	Selector   map[string]string // spec.selector.matchLabels
	Replicas   int
	Ready      int
	Available  int
	Updated    int
	Generation int
	Observed   int
}
    Workload is a Deployment or a StatefulSet.
